# Nemesis brand assets

Sourced from https://nemesis.trade/ on 2026-09-07 at the project owner's request.

- `nemesis-logo.svg`: official header logo, https://nemesis.trade/landing/logo-with-name-black.svg. The dashboard embeds its original paths with `currentColor` so it follows the selected theme.
- `favicon.ico`: official browser icon, https://nemesis.trade/favicon.ico.
- Cerebri Sans Pro regular, medium, semibold and bold: the font files served by the official site's stylesheet, https://nemesis.trade/_next/static/css/84406cc4ad93b279.css.
- Official base colors: ivory `#f7f7e8`, light surface `#fffff3`, black `#000000`, orange `#ff5e00`, dark navy `#041830`.

Secondary chart colors and accessible text/border shades are dashboard adaptations. This is an implementation based on the live site, not a claim of approval against the complete Figma brand guidelines. Assets retain their original ownership; they are included for this Nemesis dashboard.

The snapshot generator embeds the font files as data URLs; the logo is already inline. Regenerate `data/snapshot.html` after a frontend change.
