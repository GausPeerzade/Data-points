The icon area is 15 × 15 CSS pixels, matching the owner’s supplied Figma reference, with the source proportions and internal clear space preserved using `object-fit: contain`. Hyperliquid uses official color variants for theme contrast. BNB stays yellow in both themes. All files are served locally and embedded in the standalone snapshot. The old aggregator WebP thumbnails have been removed.
